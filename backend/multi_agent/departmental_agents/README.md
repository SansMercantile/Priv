# Departmental Agents

This directory contains scaffold Python modules for agents organized by department.

Guidelines:
- Each department is a subpackage (a directory) containing one or more `_agent.py` files.
- Agent modules are minimal scaffolds and should be extended with real logic as needed.
- Do not overwrite existing files; create new agents instead.

To finalize the repository (create missing `__init__.py` files and placeholder agents),
run `finalize_agents.py`.
